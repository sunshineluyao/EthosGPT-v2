# Reproduce the supplied teaching samples

This directory preserves the numerical generator and model definitions from the companion sample archive. It is separate from the extended two-group/full-distribution experiments in the parent directory.

Run `python sample_reproduction/make_figures.py` from the companion root. It writes all eight sample data outputs to `sample_reproduction/data/` and also draws the original seven sample figures for inspection. The publication figures are regenerated by the parent `make_figures.py`.

The released `sample_results/` files reproduce these eight outputs exactly. This original generator uses trapezoidal integration of sampled exposure paths; the extended mechanism integrates exposure within the differential-equation system. Minor differences in those exposure averages are reported in the paper. The phase portrait is an aggregate two-state example, while pure rate tipping and cusp examples are separate mathematical normal forms.
